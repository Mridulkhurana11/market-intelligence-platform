# Olist source data goes here

Download and extract the Brazilian E-Commerce Public Dataset by Olist:

https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce

Place these nine CSV files directly in this folder:

1. `olist_orders_dataset.csv`
2. `olist_order_items_dataset.csv`
3. `olist_customers_dataset.csv`
4. `olist_products_dataset.csv`
5. `olist_sellers_dataset.csv`
6. `olist_order_reviews_dataset.csv`
7. `olist_order_payments_dataset.csv`
8. `product_category_name_translation.csv`
9. `olist_geolocation_dataset.csv` — required for geospatial postcode-centroid and distance analysis.

Do not place the downloaded ZIP in this folder. See the repository's `DATA_LICENSE.md` before redistributing the dataset or using it beyond a non-commercial portfolio exercise.
